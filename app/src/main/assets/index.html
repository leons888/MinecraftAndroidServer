Граница runtime

Официальный BDS выпускается как Linux x86_64. Android ARM64 не запускает его напрямую. Для реального запуска приложение ожидает встроенный совместимый Box64 и glibc Linux runtime. Если runtime отсутствует или версия несовместима, будет показана ошибка, а не подставлены фальшивые данные.
